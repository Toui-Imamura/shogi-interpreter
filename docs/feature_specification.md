# 将棋指し手解釈システム 特徴量仕様書

## 1. 概要

本システムでは、将棋局面を人間が解釈可能な複数の特徴量によって評価し、
対象手の前後およびMCTSによって探索された将来局面における特徴量の変化から、
その指し手の意図を推定する。

最終的に40種類の特徴量を定義する。

各特徴量について、先手・後手それぞれの値を保持し、

    D_i = f_i^Black - f_i^White

によって両者の差を求める。

また、

    M_i = (f_i^Black + f_i^White) / 2

によって局面全体における特徴量の強度を表す。

特徴量の差だけでは「両者とも高い状態」と「両者とも低い状態」を
区別できないため、差と平均の両方を利用する。

---

## 2. 特徴量の分類

本研究では、特徴量を以下の3種類に分類する。

### A：直接的特徴量

現在の盤面から直接計算できる特徴量。

例：

- 駒得
- 持ち駒
- 駒の利き
- 玉の安全性

### B：派生的特徴量

MCTSなどによって得られた将来局面に対して特徴量を計算し、
現在局面との差として導出する特徴量。

例えば、

    Δf_i = f_i(S_future) - f_i(S_current)

とする。

本研究では、基本的な局面特徴量をAとして定義し、
MCTSによる将来局面との比較によってBの情報を生成する。

### C：独自的特徴量・手法

既存研究をそのまま利用するのではなく、本研究の指し手解釈を
目的として独自に設計する特徴量・評価方法。

# 4. F01 駒得差

## 4.1 基本情報

- ID：F01
- 名称：駒得差
- カテゴリ：Material
- 分類：A（直接的）
- 状態：確定

## 4.2 目的

現在局面において、先手と後手が盤上に保有している駒の価値を比較し、
盤上における物質的優位性を表現する。

持ち駒はF02で別途評価するため、本特徴量には含めない。

## 4.3 入力情報

現在局面の盤面を使用する。

各マスについて、

- 駒の有無
- 駒種
- 所有者

を取得する。

## 4.4 駒価値

初期値として以下の駒価値を使用する。

| 駒種 | 価値 |
|---|---:|
| 歩 | 1 |
| 香 | 3 |
| 桂 | 3 |
| 銀 | 5 |
| 金 | 6 |
| 角 | 8 |
| 飛 | 9 |
| と金 | 9 |
| 成香 | 9 |
| 成桂 | 9 |
| 成銀 | 9 |
| 馬 | 11 |
| 龍 | 12 |
| 玉 | 0 |

これらは現時点での初期パラメータである。

将来的には大量の棋譜データ等を利用して、
駒価値の調整・学習を検討する。

## 4.5 定義

先手の盤上駒価値を、

    V_B(S) = Σ v(p)

後手の盤上駒価値を、

    V_W(S) = Σ v(p)

とする。

F01は、

    F01(S) = V_B(S) - V_W(S)

と定義する。

## 4.6 内部表現

特徴量は以下の値を保持する。

- black：先手の盤上駒価値
- white：後手の盤上駒価値
- difference：先手 − 後手
- mean：先手・後手の平均

## 4.7 正規化

解釈処理等で利用する場合、

    F01_norm = tanh(F01 / τ)

とする。

現在の初期値：

    τ = 20.0

正規化値はおおむね -1～1 の範囲となる。

## 4.8 MCTSでの利用

将来局面 S_v に対しても同じ特徴量を計算する。

    ΔF01^(v) = F01(S_v) - F01(S_0)

これにより、対象手によって駒得がどのように変化したかを評価する。

複数のMCTS候補については、訪問回数等を用いて特徴量変化を集約する。

## 4.9 解釈への利用

代表的な変化：

- F01上昇 → 駒得につながる
- F01低下 → 駒損につながる
- F01変化が小さい → 駒得以外の目的である可能性

解釈例：

> 駒得を狙う手

> 駒損を回避する手

## 4.10 独立性・重複性

F02「持ち駒価値差」と関連するが、対象を分離する。

- F01：盤上の駒
- F02：持ち駒

この分離により、駒交換によって盤上価値が減少し、
同時に持ち駒価値が増加する状況を個別に観測できる。

F04「大駒バランス」およびF05「小駒バランス」は、
F01の総量そのものではなく、駒種構成の偏りを扱うことで
重複を抑える。

## 4.11 実装

実装ファイル：

    features/material.py

クラス：

    MaterialBalanceFeature

# 5. F02 持ち駒価値差

## 5.1 基本情報

- ID：F02
- 名称：持ち駒価値差
- カテゴリ：Material
- 分類：A（直接的）
- 状態：確定

## 5.2 目的

現在局面において、先手・後手が保有している持ち駒の価値を比較し、
盤上に現れていない戦力を評価する。

将棋では持ち駒を任意の空きマスに打つことができるため、
持ち駒は将来の攻撃・防御・交換等に利用できる重要な情報である。

## 5.3 入力情報

現在局面の、

    board.pieces_in_hand

を使用する。

対象となる駒種：

- 歩
- 香
- 桂
- 銀
- 金
- 角
- 飛

成駒は持ち駒として存在しないため、
未成の駒種として扱う。

## 5.4 駒価値

F01との一貫性を保つため、初期値として以下を使用する。

| 駒種 | 価値 |
|---|---:|
| 歩 | 1 |
| 香 | 3 |
| 桂 | 3 |
| 銀 | 5 |
| 金 | 6 |
| 角 | 8 |
| 飛 | 9 |

これらは初期パラメータであり、
将来的なデータによる調整を想定する。

## 5.5 定義

先手の持ち駒価値を、

    H_B(S) = Σ n_B,p × v(p)

後手の持ち駒価値を、

    H_W(S) = Σ n_W,p × v(p)

とする。

ここで、

- n_B,p：先手が保有する駒pの枚数
- n_W,p：後手が保有する駒pの枚数
- v(p)：駒pの価値

である。

F02は、

    F02(S) = H_B(S) - H_W(S)

と定義する。

## 5.6 内部表現

- black：先手の持ち駒価値
- white：後手の持ち駒価値
- difference：先手 − 後手
- mean：先手・後手の平均

## 5.7 正規化

    F02_norm = tanh(F02 / τ)

現在の初期値：

    τ = 20.0

## 5.8 MCTSでの利用

将来局面における持ち駒価値を計算し、

    ΔF02^(v) = F02(S_v) - F02(S_0)

とする。

これにより、対象手によって持ち駒の獲得・消費が
どのように変化したかを観測する。

## 5.9 解釈への利用

代表的な変化：

- 持ち駒価値増加 → 駒の獲得
- 持ち駒価値減少 → 持ち駒の使用
- 持ち駒価値増加＋攻撃圧力増加 → 攻撃準備
- 持ち駒価値増加＋玉安全性増加 → 防御資源の確保

ただし、F02単独では持ち駒の目的までは判断できない。

そのため、他の特徴量との組み合わせによって解釈する。

## 5.10 独立性・重複性

F01「駒得差」と同じMaterialカテゴリに属するが、
対象とする駒の場所が異なる。

- F01：盤上の駒
- F02：持ち駒

例えば駒交換によって、

    盤上駒価値 ↓
    持ち駒価値 ↑

となる場合、それぞれを別の特徴量として観測できる。

これにより、

> 駒を失った

だけでなく、

> 駒交換によって持ち駒を獲得した

という局面変化を区別できる。

## 5.11 実装

実装ファイル：

    features/material.py

クラス：

    HandPieceBalanceFeature

# 6. 特徴量の共通インターフェース

すべての特徴量は共通して以下の情報を持つ。

    feature_id
    name
    category
    classification

特徴量抽出時には、

    FeatureValue(
        black=...,
        white=...
    )

を返す。

FeatureValueは以下の派生値を提供する。

    difference = black - white

    mean = (black + white) / 2

これにより、各特徴量を同一形式で扱う。

---

# 7. 特徴量の正規化

特徴量によって値のスケールが異なるため、
必要に応じて正規化した値を使用する。

基本的には、

    f_norm = tanh(f / τ)

によって値を -1～1 の範囲へ変換する。

ただし、すべての特徴量で同一の τ を使用するとは限らない。

各特徴量の値域や分布を実験によって確認し、
適切な正規化方法を決定する。

正規化パラメータは現時点では初期値として設定し、
大量の棋譜データを利用した実験によって調整する。

---

# 8. 特徴量の差分

本研究では、対象手そのものによる局面変化と、
MCTSによって得られた将来局面における変化を分析する。

現在局面を、

    S_0

対象手を適用した後の局面を、

    S_1

MCTSによって得られた将来局面を、

    S_v

とする。

## 8.1 対象手による変化

各特徴量について、

    Δf_i_move = f_i(S_1) - f_i(S_0)

を計算する。

これにより、対象手によって局面がどの方向に変化したかを確認する。

## 8.2 MCTSによる将来変化

各MCTS候補について、

    Δf_i^(v) = f_i(S_v) - f_i(S_0)

を計算する。

これにより、対象手の後に展開される局面において、
どの特徴量が継続的に変化するかを分析する。

---

# 9. MCTSによる解釈

MCTSでは対象手以降の複数の候補変化を探索する。

候補となる変化 v ごとに訪問回数 N_v を取得し、

    α_v = N_v / Σ N_u

によって正規化する。

特徴量変化の集約値を、

    Δf_i_bar = Σ α_v Δf_i^(v)

とする。

これによって、MCTSによって重点的に探索された局面で
共通して現れる特徴量変化を重視する。

ただし、MCTSの訪問回数は、

- 指し手の正しさ
- 指し手の意図
- 人間にとっての重要性

そのものを意味するものではない。

したがって、本研究では訪問回数を
「解釈候補を集約する際の重要度」として利用する。

---

# 10. 指し手解釈

対象手の意図は、単一の特徴量だけでなく、
複数の特徴量変化を組み合わせて推定する。

例えば、

    駒得差 ↑
    攻撃圧力 ↑
    攻撃参加駒数 ↑

という変化が複数のMCTS候補で確認された場合、

    「駒得を狙いながら攻撃態勢を強化する手」

などの解釈候補を生成する。

一方、

    玉の安全性 ↑
    玉周辺の守備駒数 ↑
    攻撃圧力 ↓

であれば、

    「自玉の安全確保を優先する手」

などの解釈候補を生成する。

最終的には特徴量変化の大きさ、
MCTSにおける出現頻度、
複数特徴量間の関係を考慮して、
2～3個程度の主要な解釈候補を出力することを目標とする。

解釈は断定的に、

    「この手の目的は○○である」

とするのではなく、

    「この手は○○を狙った可能性が高い」

のように、分析結果に基づく推定として表現する。

# 11. 動的な特徴量重み

本研究では、特徴量の重みを固定値として扱わない。

将棋では、同じ特徴量であっても局面の進行状況によって
重要性が変化するためである。

例えば、

- 序盤：駒組みや陣形の重要性が高い
- 中盤：攻撃・守備・駒の連携の重要性が高い
- 終盤：玉の安全性や攻撃の重要性が高い

といった違いが考えられる。

ただし、本研究では単純に手数だけで
序盤・中盤・終盤を決定しない。

現在局面の、

- 手数
- 先手・後手の特徴量差
- 特徴量の平均
- 駒得
- 持ち駒
- 攻撃状態
- 玉の安全性
- 陣形
- 駒交換状況

などを利用して局面状態を推定する。

局面状態を、

    Z = (P, D, I)

とする。

- P：局面の進行状態
- D：形勢の偏り
- I：戦闘・戦術的な強度

局面進行状態Pは、

    P = [P_E, P_M, P_L]

として序盤・中盤・終盤への所属度を連続値で表現する。

特徴量の重みは、

    w_i(S)
      = P_E w_i^E
      + P_M w_i^M
      + P_L w_i^L

とする。

これにより、例えば手数が進んでいても局面の特徴から
中盤的な状態である場合には、中盤寄りの重みを維持できる。

詳細は、

    docs/dynamic_weight_specification.md

で定義する。

「盤面への影響」を中心とする。

F07は各駒が実際にどの程度移動可能であるかという
「移動可能性」を中心とする。

今後、新しい特徴量を追加する際にも、
既存特徴量との意味的・数値的な重複を確認する。

# 15. 今後の研究上の検討事項

今後の実装では、単純に40個の特徴量を実装するのではなく、
以下を検証する。

### 15.1 特徴量の妥当性

各特徴量が実際に将棋局面の重要な性質を表現できているかを確認する。

### 15.2 特徴量間の重複

相関分析等を用いて、異なる特徴量がほぼ同じ情報を表現していないかを確認する。

### 15.3 重みの学習

大量の棋譜データを利用し、
特徴量の重みを調整する方法を検討する。

### 15.4 局面状態による重みの変化

序盤・中盤・終盤を手数だけで分類せず、
現在局面の特徴から重みを動的に変化させる方法を検討する。

### 15.5 MCTSとの組み合わせ

MCTSによる将来局面探索と特徴量変化を組み合わせることで、
対象手の短期的・中期的な影響を分析する。

### 15.6 解釈の評価
