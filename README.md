# Shogi Move Interpreter

将棋AIの指し手を、局面特徴量とMCTSによる将来局面の変化から
解釈する卒業研究システム。

## 研究目的

将棋AIが選択した指し手について、単純な評価値だけではなく、

- 駒得
- 駒の活動性
- 攻撃
- 防御
- 駒同士の連携
- 陣形
- 玉の安全性
- 歩の構造

などの人間が理解可能な特徴量を用いて、
「なぜその指し手が有効なのか」を解釈する。

## 基本方針

現在局面から40個の特徴量を計算する。

MCTSによって将来局面を探索し、
将来局面についても同じ40特徴量を計算する。

現在局面と将来局面の特徴量の変化を分析し、
複数の変化手に共通する特徴変化から
指し手の意図を推定する。

## 特徴量分類

### A：直接的特徴量

現在局面から直接計算する特徴量。

### B：派生的特徴量

MCTSによる将来局面から、
Aの特徴量の変化・推移として導出する特徴量。

### C：独自特徴量

本研究で新たに提案する解釈指標や分析方法。

## 研究システム

40特徴量
→ 局面状態推定
→ 動的重み付け
→ NNUE + MCTS
→ 将来局面の特徴量変化
→ 指し手解釈
